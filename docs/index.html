Wolfpole v1.0.0 · SF2000

Build cards you can trust.

Wolfpole is an SF2000 SD card manager — a rewrite of Madpole (fork of Tadpole), with a checked card-building pipeline, cover-grid library, and the quality-of-life fixes the original never got.

View on GitHub Install Reddit posts

Requires Python 3, PyQt5 or PyQt6, plus psutil and requests.

Build pipeline

  1. 1
    Pre-flight
    FAT32, capacity sanity, empty card, write/read test, speed check.
  2. 2
    Download
    Resumable, retried, SHA-256 verified, cached off-card.
  3. 3
    Inspect archive
    Zip-slip blocked before extraction, junk stripped.
  4. 4
    Extract + verify
    Per-file CRC on write, full re-read verification by default.
  5. 5
    Resume + rescue
    Manifest-backed resume, deep card test, doctor checks.

Why Wolfpole

Stops at the first bad stage

Counterfeit cards, truncated downloads, exFAT volumes, and zip-slip paths are caught before you boot a dead card.

Cover grid that stays live

Box-art tiles, shortcut slots, drag-and-drop ROMs and artwork, and folder watching that debounces sensibly.

Headless when you want it

Rebuild indexes, back up saves, and list drives from the command line — no GUI import required.

Quality of life

Library tools

All-systems view, filter chips for missing art / shortcuts / multicore / large files, duplicate finder, tidy ROM names, export shortcut layout.

Rescue & overview

Card health bars, missing-folder repair, staged firmware detection, low-space warnings, and a real safe-eject that flushes per platform.

Keyboard-first UI

Command palette with Ctrl+K, activity log with Ctrl+L, grid/list toggle, session restore.

Fixed what was broken

Thumbnails no longer point at freed memory, renames hit the right row, deletes count once, network and disk I/O stay off the GUI thread.

Install

git clone https://github.com/Wolfodia/wolfpole.git
cd wolfpole
pip install -r requirements.txt

# Drop wolfpole.py, wolfpole_ui.py, wolfpole_core.py, wolfpole_builder.py
# beside your Tadpole/Madpole checkout, then:
python wolfpole.py

Command line

python wolfpole.py --list-drives
python wolfpole.py --drive E:\ --rebuild ALL
python wolfpole.py --drive E:\ --backup-saves ~/backups
python wolfpole.py --portable --theme dark --offline --verbose
